# 工程驗收與結案管理

> 模組名稱: `construction_acceptance`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程專案的驗收與結案功能，包含初驗、正驗、驗收缺失追蹤與結案處理。

## 主要功能

### 1. 初驗管理 (acceptance.preliminary)
- 工程竣工後的初次驗收
- 驗收人員與日期記錄
- 缺失發現與改善期限設定

### 2. 正驗管理 (acceptance.final)
- 初驗缺失改善後的正式驗收
- 最終驗收結果判定
- 驗收合格證明

### 3. 驗收缺失追蹤 (acceptance.defect)
- 驗收發現的缺失追蹤
- 改善期限與進度管理
- 覆驗記錄

### 4. 結案處理 (project.closure)
- 驗收合格後的結案程序
- 保固期設定與管理
- 保留款退還追蹤


## 操作說明

### 建立初驗紀錄
1. 進入「驗收結案 > 初驗管理 > 初驗紀錄」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 填寫初驗資訊：
   - 初驗日期
   - 驗收人員
   - 驗收範圍
5. 進行現場驗收
6. 記錄驗收結果與發現的缺失
7. 設定缺失改善期限

### 追蹤驗收缺失
1. 進入「驗收缺失 > 驗收缺失清單」
2. 查看初驗/正驗發現的缺失
3. 追蹤改善進度
4. 改善完成後申請覆驗
5. 覆驗通過後結案

### 執行正驗
1. 初驗缺失全部改善完成
2. 進入「正驗管理 > 正驗紀錄」建立正驗
3. 選擇對應的初驗紀錄
4. 填寫正驗資訊
5. 執行正式驗收
6. 判定最終驗收結果

### 辦理結案
1. 正驗合格後，進入「結案管理 > 結案處理」
2. 建立結案紀錄
3. 確認結案文件齊全：
   - 驗收合格證明
   - 結算書
   - 保固切結書
4. 設定保固期間
5. 完成結案

### 保固期管理
1. 進入「結案管理 > 保固中工程」
2. 查看保固期內的工程
3. 處理保固期間的維修事項
4. 保固期滿後辦理退還保留款

## 驗收流程

```
工程竣工
    ↓
初驗申請 → 初驗執行 → 缺失改善 → 覆驗
                              ↓
                          正驗申請 → 正驗執行
                                        ↓
                                    驗收合格 → 結案 → 保固期 → 保留款退還
```

## 驗收結果

| 結果 | 說明 |
|------|------|
| 合格 | 驗收通過，無缺失 |
| 部分合格 | 有輕微缺失，需改善 |
| 不合格 | 有重大缺失，需重新驗收 |
