# 工程監造系統 - 稽核模組

> 模組名稱: `construction_audit`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供系統操作軌跡記錄功能，追蹤重要操作的變更歷史。

## 主要功能

### 操作軌跡記錄 (audit.trail)
- 追蹤建立、修改、刪除操作
- 記錄狀態變更
- 變更前後值對比
- 操作者與時間記錄

## 選單位置

```
系統設定
└── 稽核管理
    ├── 所有記錄
    ├── 依模型查看
    ├── 依操作者查看
    └── 狀態變更記錄
```

## 操作說明

### 查看所有稽核記錄
1. 進入「系統設定 > 稽核管理 > 所有記錄」
2. 查看系統所有操作軌跡
3. 可依日期、模型、操作者篩選

### 依模型查看
1. 進入「稽核管理 > 依模型查看」
2. 選擇要查看的模型（如：工程案件、施工日誌）
3. 查看該模型的所有操作記錄

### 依操作者查看
1. 進入「稽核管理 > 依操作者查看」
2. 選擇要查看的使用者
3. 查看該使用者的所有操作記錄

### 查看狀態變更記錄
1. 進入「稽核管理 > 狀態變更記錄」
2. 查看所有狀態變更操作
3. 追蹤審核流程的執行情況

### 查看特定記錄的變更歷史
1. 開啟任一業務記錄（如工程案件）
2. 點擊「稽核軌跡」按鈕
3. 查看該記錄的完整變更歷史
4. 比對變更前後的值

## 記錄類型

| 類型 | 說明 |
|------|------|
| 建立 | 記錄建立時間與建立者 |
| 修改 | 記錄欄位變更前後值 |
| 刪除 | 記錄刪除時間與刪除者 |
| 狀態變更 | 記錄狀態轉換過程 |

## 追蹤欄位

系統會追蹤以下類型的欄位變更：
- 狀態欄位（state）
- 金額欄位
- 日期欄位
- 關聯欄位（Many2one）
- 文字欄位

## 使用情境

1. **審計追蹤**
   - 追蹤誰在何時修改了資料
   - 提供完整的操作歷史

2. **問題調查**
   - 調查資料異常的原因
   - 追溯變更來源

3. **合規要求**
   - 滿足稽核與合規需求
   - 提供操作證據
