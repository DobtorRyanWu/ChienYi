# 工程監造系統 - 人機管理

> 模組名稱: `construction_equipment`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供施工機具設備管理功能，包含設備主檔、維護請求與人機項目管理。

## 主要功能

### 1. 機具設備分類 (supervision.equipment.category)
- 樹狀分類結構
- 設備分類管理

### 2. 機具設備管理 (supervision.equipment)
- 設備主檔建立
- 設備基本資料維護
- MTBF/MTTR 效能指標自動計算
- 設備狀態追蹤

### 3. 維護請求 (supervision.equipment.request)
- 設備維護請求建立
- 看板式工作流程管理
- 糾正性維護與預防性維護
- 循環維護排程

### 4. 人機項目主檔 (daily.log.man.machine)
- 工程級人機項目設定
- 人員與機具單價管理
- 使用量自動累計統計

### 5. 施工日誌人機使用明細 (daily.log.man.machine.detail)
- 在施工日誌中選擇人機項目登記使用量
- 自動計算當日金額
- 累計回主檔

## 操作說明

### 建立人機項目
1. 進入「施工執行 > 人機管理 > 人機記錄 > 所有人機記錄」
2. 點擊「建立」按鈕
3. 填寫項目資訊：
   - 所屬工程
   - 記錄類型（人員/機具）
   - 人員類型 或 機具名稱
   - 單價、計價單位
4. 儲存項目

### 在施工日誌中登記使用量
1. 進入「施工日誌」表單
2. 切換到「人機使用」頁籤
3. 點擊「新增一行」
4. 選擇人機項目（從下拉選單）
5. 填寫使用時數、數量
6. 系統自動計算金額
7. 可選擇性填寫具體人員或設備

### 查看統計
1. 進入「人機記錄 > 所有人機記錄」
2. 查看各項目的總時數、總金額
3. 點擊項目可查看詳細使用明細

## 使用流程範例

```
步驟1: 建立人機項目主檔
  工程: XX大樓工程
  機具名稱: 抽水機
  單價: 50元/小時

步驟2: 施工日誌登記
  第1天: 選擇"抽水機" → 使用8小時 → 自動計算400元
  第2天: 選擇"抽水機" → 使用6小時 → 自動計算300元
  第3天: 選擇"抽水機" → 使用10小時 → 自動計算500元

步驟3: 查看統計
  抽水機: 總時數24小時，總金額1,200元
```
