# 工程監造系統 - 人機管理

> 模組名稱: `construction_equipment`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供施工機具設備管理功能，包含設備主檔、維護請求與人機記錄管理。

## 主要功能

### 1. 機具設備分類 (supervision.equipment.category)
- 樹狀分類結構
- 設備分類管理

### 2. 機具設備管理 (supervision.equipment)
- 設備主檔建立
- 設備基本資料維護
- MTBF/MTTR 效能指標自動計算
- 設備狀態追蹤

### 3. 維護請求 (supervision.equipment.request)
- 設備維護請求建立
- 看板式工作流程管理
- 糾正性維護與預防性維護
- 循環維護排程

### 4. 人機記錄 (daily.log.man.machine)
- 施工日誌人機投入記錄
- 人員出工統計
- 機具使用統計

## 選單位置

```
施工執行
└── 人機管理
    ├── 機具設備
    │   ├── 機具設備
    │   └── 維護中設備

└── 設備設定
    ├── 機具設備分類
    └── 維護請求階段
```

## 操作說明

### 建立機具設備
1. 進入「施工執行 > 人機管理 > 機具設備 > 機具設備」
2. 點擊「建立」按鈕
3. 填寫設備資訊：
   - 設備編號、名稱
   - 設備分類
   - 規格型號
   - 使用狀態
4. 儲存設備資料

### 建立維護請求
1. 進入「人機管理 > 維護請求 > 所有維護請求」
2. 點擊「建立」按鈕
3. 選擇需維護的設備
4. 填寫維護內容說明
5. 設定維護類型（糾正性/預防性）
6. 指派維護人員
7. 使用看板追蹤維護進度

### 記錄人機投入
1. 在施工日誌中新增人機記錄
2. 選擇記錄類型（人員/機具）
3. 填寫投入數量與時數
4. 系統自動彙整統計

### 查看統計報表
1. 進入「人機記錄 > 人員出工統計」查看人員統計
2. 進入「人機記錄 > 機具使用統計」查看機具統計
3. 可依日期、工程案件篩選
