# 工程監造系統 - 價格庫管理

> 模組名稱: `construction_price_library`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程常用工項的標準單價資料庫功能，方便快速建立契約工項。

## 主要功能

### 1. 價格庫分類 (price.library.category)
- 樹狀分類結構
- 多層級分類管理

### 2. 價格庫項目 (price.library.item)
- 標準工項單價
- 成本組成資訊
- 價格變更歷史

### 3. 價格庫匯入精靈
- 快速匯入契約工項
- 批次匯入支援

## 選單位置

```
工程管理
└── 工程總覽
    └── 從價格庫匯入工項

系統設定
└── 價格庫
    ├── 價格庫分類
    ├── 價格庫項目
    └── 價格變更歷史
```

## 操作說明

### 管理價格庫分類
1. 進入「系統設定 > 價格庫 > 價格庫分類」
2. 建立分類結構，例如：
   - 土木工程
     - 基礎工程
     - 結構工程
   - 機電工程
     - 電氣工程
     - 給排水工程
3. 設定分類層級關係

### 建立價格庫項目
1. 進入「價格庫 > 價格庫項目」
2. 點擊「建立」按鈕
3. 填寫工項資訊：
   - 工項編號
   - 工項名稱
   - 單位
   - 標準單價
   - 所屬分類
4. 填寫成本組成（可選）：
   - 材料費
   - 工資
   - 機具費
   - 管理費
5. 儲存項目

### 更新價格
1. 開啟價格庫項目
2. 修改單價
3. 儲存時系統自動記錄價格變更歷史
4. 可在「價格變更歷史」查看歷次變更

### 匯入契約工項
1. 進入「工程管理 > 工程總覽 > 從價格庫匯入工項」
2. 選擇目標工程案件
3. 勾選要匯入的價格庫項目
4. 調整數量
5. 點擊「匯入」按鈕
6. 系統自動建立契約工項

## 成本組成

| 項目 | 說明 |
|------|------|
| 材料費 | 工項所需材料成本 |
| 工資 | 人工費用 |
| 機具費 | 機具設備使用費 |
| 管理費 | 間接管理成本 |
| 利潤 | 預計利潤 |

## 使用情境

1. **新專案快速建立工項**
   - 從價格庫批次匯入常用工項
   - 減少重複輸入

2. **標準化報價**
   - 使用統一的標準單價
   - 確保報價一致性

3. **成本分析**
   - 透過成本組成分析利潤
   - 優化報價策略
