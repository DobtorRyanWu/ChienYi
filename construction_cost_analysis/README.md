# 工程成本分析

> 模組名稱: `construction_cost_analysis`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程專案的成本分析功能，支援多維度分析與即時損益計算。

## 主要功能

### 1. 成本分析報表 (cost.analysis.report)
- 契約金額 vs 實際執行金額
- 各工項損益計算
- 多維度分析

### 2. 成本分析摘要 (cost.analysis.summary)
- 按專案彙總
- 執行率與估驗率追蹤
- 預估損益分析

## 選單位置

```
計價請款
└── 成本分析
    ├── 成本分析報表
    ├── 成本分析摘要
    └── 即時損益
```

## 操作說明

### 查看成本分析報表
1. 進入「計價請款 > 成本分析 > 成本分析報表」
2. 選擇工程案件
3. 查看各工項的成本分析：
   - 契約金額
   - 實際執行金額
   - 差異金額
   - 損益率
4. 使用樞紐分析功能多維度分析

### 查看成本分析摘要
1. 進入「成本分析 > 成本分析摘要」
2. 查看專案層級的彙總資訊：
   - 原契約金額
   - 變更金額
   - 現行契約金額
   - 累計估驗金額
   - 執行率
   - 估驗率
3. 比較各專案的執行狀況

### 即時損益分析
1. 進入「成本分析 > 即時損益」
2. 查看即時的損益狀況
3. 分析利潤與成本結構
4. 預估最終損益

### 匯出報表
1. 使用篩選器選擇資料範圍
2. 切換至樞紐或圖表視圖
3. 點擊匯出按鈕
4. 選擇匯出格式（Excel/PDF）

## 分析維度

| 維度 | 說明 |
|------|------|
| 按工項 | 各工項的成本分析 |
| 按廠商 | 各分包廠商的成本分析 |
| 按月份 | 按月份的成本趨勢 |
| 按專案 | 專案層級的彙總 |

## 關鍵指標

| 指標 | 計算公式 |
|------|----------|
| 執行率 | 實際執行金額 ÷ 契約金額 × 100% |
| 估驗率 | 累計估驗金額 ÷ 契約金額 × 100% |
| 損益率 | (契約金額 - 成本) ÷ 契約金額 × 100% |
