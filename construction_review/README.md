# 工程監造系統 - 送審管制模組

> 模組名稱: `construction_review`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程材料送審管制功能，追蹤材料型錄、樣品與測試報告的審查狀態。

## 主要功能

### 送審管制 (supervision.review.application)
- 材料送審申請
- 審查流程追蹤
- 審查結果管理
- 廠驗與取樣試驗管理
- 歸檔編號管理

## 選單位置

```
工程管理
└── 文件管理
    ├── 送審管制表
    ├── 待審查送審
    └── 已核定送審
```

## 操作說明

### 建立送審申請
1. 進入「工程管理 > 文件管理 > 送審管制表」
2. 點擊「建立」按鈕
3. 選擇工程案件與工項
4. 填寫送審資訊：
   - 送審項目名稱
   - 送審資料類型（型錄/樣品/測試報告）
   - 預定送審日期
   - 實際送審日期
5. 上傳送審文件
6. 儲存並提交審查

### 審查送審資料
1. 審查人員進入「待審查送審」
2. 檢視送審文件內容
3. 填寫審查意見
4. 選擇審查結果：
   - **合格**：審查通過
   - **條件式通過**：需補正後通過
   - **不合格**：退回重送
5. 完成審查

### 追蹤送審進度
1. 進入送審管制表
2. 查看各項目送審狀態
3. 依狀態篩選：草稿、已提交、審查中、已核定
4. 匯出送審進度報表

### 管理歸檔編號
1. 審查通過後填寫歸檔編號
2. 記錄文件歸檔位置
3. 方便後續查閱

## 狀態流程

```
草稿 (draft)
    ↓
已提交 (submitted)
    ↓
審查中 (reviewing)
    ↓
已核定 (approved) ←→ 已駁回 (rejected)
```

## 審查結果

| 結果 | 說明 |
|------|------|
| 合格 | 審查通過，可使用 |
| 條件式通過 | 需補正特定項目後通過 |
| 不合格 | 需重新送審 |

## 送審資料類型

| 類型 | 說明 |
|------|------|
| 材料型錄 | 材料規格型錄 |
| 材料樣品 | 實體樣品送審 |
| 測試報告 | 材料測試報告 |
| 施工計畫 | 施工方法計畫書 |
| 品質計畫 | 品質管理計畫 |
