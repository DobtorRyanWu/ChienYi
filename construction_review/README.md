# 工程監造系統 - 送審管制模組

> 模組名稱: `construction_review`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程材料送審管制功能，用於記錄和追蹤材料型錄、樣品與測試報告的送審資訊。

## 主要功能

### 送審管制 (supervision.review.application)
- 材料送審記錄
- 送審資料管理
- 審查結果記錄
- 廠驗與取樣試驗資訊
- 歸檔編號管理

## 選單位置

```
工程管理
├── 送審管制表 (所有送審記錄)
├── 編輯中送審 (編輯中)
└── 已完成送審 (已完成)
```

## 操作說明

### 建立送審記錄
1. 進入「工程管理 > 送審管制表」
2. 點擊「建立」按鈕
3. 選擇工程案件與工項
4. 填寫送審資訊：
   - 材料名稱
   - 契約詳細表項次
   - 契約數量
   - 預定送審日期
   - 實際送審日期
5. 選擇送審資料類型（型錄/樣品/測試報告/協力廠商/其他）
6. 上傳送審文件
7. 填寫審查結果
8. 點擊「完成」按鈕

### 編輯送審記錄
1. 進入「編輯中送審」查看未完成的記錄
2. 開啟記錄進行編輯
3. 完成後點擊「完成」按鈕
4. 系統會自動產生送審編號

### 查看已完成記錄
1. 進入「已完成送審」查看所有已完成的記錄
2. 可依所屬工程分組查看
3. 管理者可使用「重設為編輯中」按鈕重新編輯

### 追蹤送審進度
1. 進入送審管制表
2. 預設依所屬工程分組顯示
3. 可查看各項目送審狀態
4. 依狀態篩選：編輯中、已完成
5. 匯出送審進度報表

## 狀態流程

```
編輯中 (draft)
    ↓
   [完成]
    ↓
已完成 (done)
```

**說明**：
- **編輯中**：記錄可隨時編輯修改
- **已完成**：記錄完成，系統自動產生送審編號

## 送審資料類型

| 類型 | 說明 |
|------|------|
| 型錄 | 材料規格型錄 |
| 樣品 | 實體樣品送審 |
| 測試報告 | 材料測試報告 |
| 協力廠商 | 協力廠商資料 |
| 其他 | 其他送審資料（需填寫說明） |

## 審查結果

| 結果 | 說明 |
|------|------|
| 合格 | 審查通過，可使用 |
| 條件式通過 | 需補正特定項目後通過 |
| 不合格 | 需重新送審 |

## 功能特點

- **簡化流程**：移除複雜的審核流程，專注於資訊記錄
- **自動編號**：完成時自動產生送審編號
- **彈性編輯**：編輯中狀態可隨時修改
- **分組檢視**：預設依所屬工程分組顯示
- **完整記錄**：包含廠驗、試驗、審查、歸檔等資訊
