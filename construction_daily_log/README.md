# 工程監造系統 - 施工日誌

> 模組名稱: `construction_daily_log`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供施工日誌管理功能，採用 Sheet 聚合模式設計，可將多日施工記錄整合於同一份日誌表單中。

## 主要功能

### 1. 施工日誌表單 (daily.log.sheet)
- 聚合多日施工日誌明細
- 支援日期區間管理
- 四態工作流程：新建 → 草稿 → 待審核 → 已核准
- 審核人員與審核意見記錄

### 2. 施工日誌明細 (daily.log.line)
- 每日施工作業記錄
- 工項進度登錄
- 施工人力與機具投入
- 施工狀況描述

### 3. 天氣記錄 (daily.log.weather)
- 每日天氣狀況記錄
- 天氣對施工的影響說明
- 是否停工標記

## 選單位置

```
施工執行
└── 施工日誌
    ├── 我的日誌
    ├── 所有日誌
    ├── 待審核
    ├── 批次下載
    └── 設定
        ├── 日誌明細
        └── 天氣記錄
```

## 操作說明

### 建立施工日誌
1. 進入「施工執行 > 施工日誌 > 我的日誌」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 設定日誌日期區間（例如：一週）
5. 儲存後開始填寫每日明細

### 填寫每日施工記錄
1. 在日誌表單中點擊「新增」
2. 選擇日期
3. 填寫施工內容：
   - 工項進度
   - 投入人力與機具
   - 施工狀況說明
   - 特殊事項備註
4. 上傳當日施工照片（可選）

### 記錄天氣狀況
1. 在日誌中點擊天氣記錄
2. 選擇天氣類型（晴/陰/雨等）
3. 記錄對施工的影響
4. 如因天候停工，勾選「停工」

### 提交審核
1. 確認所有資料填寫完整
2. 點擊「提交審核」按鈕
3. 狀態變更為「待審核」
4. 監造人員進行審核
5. 審核通過後狀態變更為「已核准」

## 工作流程

```
新建 → 草稿 → 待審核 → 已核准
              ↓
           退回修改
```
