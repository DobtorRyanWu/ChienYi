# 工程監造系統 - 核心基礎模組

> 模組名稱: `construction_supervision_base`
> 版本: 18.0.1.0.0

## 模組說明

此模組是工程監造系統的核心基礎模組，提供系統的基本架構、權限控制與主要資料模型。

## 主要功能

### 1. 工程案件管理 (supervision.project)
- 工程案件主檔建立與維護
- 支援一般式與預約式工程類型
- 完整的工程基本資料設定
- 專案狀態追蹤

### 2. 契約工項管理 (project.task 擴展)
- 繼承 Odoo 專案任務模型
- 契約工項清單維護
- 工項數量、單價、金額管理
- 執行進度追蹤

### 3. 工程文件管理 (supervision.document)
- 工程相關文件上傳與管理
- 文件審查流程
- 待審查文件追蹤

### 4. 多公司架構支援
- 設計監造單位與施工廠商分離
- 資料隔離與存取控制
- 完整的權限控制機制

## 操作說明

### 建立工程案件
1. 進入「工程管理 > 工程總覽 > 工程案件」
2. 點擊「建立」按鈕
3. 填寫工程基本資料：
   - 工程編號（自動產生）
   - 工程名稱
   - 工程類型（一般式/預約式）
   - 業主、施工廠商、監造單位
   - 契約金額、工期等
4. 儲存後可開始新增契約工項

### 管理契約工項
1. 進入「工程管理 > 工程總覽 > 契約工項」
2. 選擇對應的工程案件
3. 新增工項資料：
   - 工項編號、名稱
   - 單位、數量、單價
   - 預定開始與結束日期
4. 系統自動計算工項金額

### 工程文件管理
1. 進入「工程管理 > 文件管理 > 工程文件」
2. 上傳工程相關文件
3. 設定文件類型與說明
4. 需審查的文件會出現在「待審查文件」
