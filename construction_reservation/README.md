# 工程監造系統 - 預約式工程專用模組

> 模組名稱: `construction_reservation`
> 版本: 18.0.1.0.0

## 模組說明

此模組整合通報單與品質管理功能，專供預約式工程使用。

## 主要功能

### 1. 通報單擴展
- 整合自主檢查管理
- 整合缺失改善管理
- 統計分析功能

### 2. 預約式自主檢查增強
- 從通報單直接建立
- 快速導覽功能
- 統計資訊顯示

### 3. 預約式缺失改善增強
- 從通報單直接管理
- 從自主檢查缺失項目自動建立
- 改善進度追蹤

## 選單位置

此模組主要透過通報單介面操作，不單獨設置選單。

功能整合於：
```
施工執行
└── 通報單管理
    └── 通報單  ← 整合自主檢查與缺失改善

品質安全
├── 自主檢查
│   └── 預約式自主檢查
└── 缺失管理
    └── 預約式缺失改善
```

## 操作說明

### 從通報單管理自主檢查
1. 開啟已核准的通報單
2. 查看「自主檢查」頁籤
3. 點擊「建立自主檢查」
4. 系統自動帶入通報單資訊
5. 執行檢查並記錄結果

### 從自主檢查建立缺失改善
1. 在自主檢查表中標記不合格項目
2. 點擊「建立缺失改善」按鈕
3. 系統自動從缺失項目建立改善記錄
4. 填寫改善期限與負責人
5. 開始追蹤改善進度

### 從通報單追蹤缺失改善
1. 開啟通報單
2. 查看「缺失改善」頁籤
3. 查看相關的缺失改善記錄
4. 點擊進入詳細頁面
5. 更新改善進度

### 查看統計資訊
1. 在通報單上查看統計：
   - 自主檢查數量
   - 缺失改善數量
   - 已結案比例
2. 使用智能按鈕快速導覽

## 預約式工程流程

```
通報單建立
    ↓
通報單核准
    ↓
施工執行 ──→ 自主檢查 ──→ 發現缺失 ──→ 缺失改善
    ↓                                    ↓
施工完成                              改善完成
    ↓                                    ↓
通報單驗收 ←─────────────────────────────┘
    ↓
驗收完成
```

|------|----------------|----------------|
