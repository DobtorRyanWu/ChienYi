# 工程監造系統 - 樣板設定

> 模組名稱: `construction_template`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供文件樣板管理功能，支援施工日誌、自主檢查表、估驗計價表等文件的樣板設定。

## 主要功能

### 文件樣板管理 (document.template)
- 多種樣板類型支援
- 系統預設與專案自訂
- 樣板上傳與下載
- 欄位對照表設定

## 選單位置

```
系統設定
└── 樣板設定
    ├── 所有樣板
    └── 依類型
        ├── 施工日誌樣板
        ├── 自主檢查樣板
        ├── 缺失改善樣板
        ├── 估驗計價樣板
        └── 進度報告樣板
```

## 操作說明

### 上傳文件樣板
1. 進入「系統設定 > 樣板設定 > 所有樣板」
2. 點擊「建立」按鈕
3. 填寫樣板資訊：
   - 樣板名稱
   - 樣板類型
   - 適用範圍（系統/公司/專案）
4. 上傳樣板檔案（Excel/Word）
5. 設定欄位對照表（JSON 格式）
6. 儲存樣板

### 設定欄位對照
1. 開啟樣板記錄
2. 在「欄位對照」頁籤設定對應關係
3. 格式範例：
   ```json
   {
     "project_name": "A1",
     "date": "B1",
     "weather": "C1"
   }
   ```
4. 儲存設定

### 指定專案樣板
1. 開啟工程案件
2. 在「樣板設定」頁籤
3. 為各文件類型指定專用樣板
4. 未指定時使用公司預設或系統預設

### 測試樣板
1. 開啟樣板記錄
2. 點擊「測試樣板」按鈕
3. 選擇測試資料
4. 產生測試文件
5. 確認格式正確

## 樣板類型

| 類型 | 說明 |
|------|------|
| 施工日誌 | 每日施工記錄報表 |
| 自主檢查 | 自主檢查表格式 |
| 缺失改善 | 缺失改善追蹤表 |
| 估驗計價 | 估驗計價表格式 |
| 進度報告 | 進度報告格式 |

## 樣板優先順序

```
1. 專案專屬樣板（最高優先）
       ↓
2. 公司預設樣板
       ↓
3. 系統預設樣板（最低優先）
```

## 支援格式

| 格式 | 副檔名 | 說明 |
|------|--------|------|
| Excel | .xlsx | 表格類文件 |
| Word | .docx | 報告類文件 |
