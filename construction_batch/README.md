# 工程監造系統 - 批次操作

> 模組名稱: `construction_batch`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程監造系統的批次操作功能，支援文件批次下載。

## 主要功能

### 批次下載精靈 (batch.download.wizard)
- 施工日誌批次下載
- 自主檢查表批次下載
- 估驗計價表批次下載
- 檢試驗記錄批次下載

## 選單位置

```
施工執行
└── 施工日誌
    └── 批次下載

計價請款
└── 報表下載
    └── 批次下載
```

## 操作說明

### 批次下載施工日誌
1. 進入「施工執行 > 施工日誌 > 批次下載」
2. 開啟批次下載精靈
3. 設定下載條件：
   - 選擇工程案件
   - 設定日期區間
   - 選擇下載格式（PDF/Excel）
4. 勾選要下載的日誌（或留空自動選取）
5. 點擊「開始下載」
6. 系統產生 ZIP 壓縮檔
7. 下載壓縮檔

### 批次下載估驗計價表
1. 進入「計價請款 > 報表下載 > 批次下載」
2. 選擇下載類型：估驗計價
3. 設定篩選條件：
   - 工程案件
   - 日期區間
   - 估驗狀態
4. 選擇下載格式
5. 點擊「開始下載」

### 預覽待下載記錄
1. 設定篩選條件後
2. 點擊「預覽記錄」按鈕
3. 查看符合條件的記錄清單
4. 確認無誤後執行下載

## 下載類型

| 類型 | 說明 |
|------|------|
| 施工日誌 | 每日施工記錄 |
| 估驗計價 | 估驗計價表 |
| 自主檢查 | 自主檢查表（開發中） |
| 檢試驗記錄 | 檢試驗管制記錄（開發中） |

## 下載格式

| 格式 | 說明 |
|------|------|
| PDF | 適合列印與歸檔 |
| Excel | 適合資料分析 |

## 下載選項

| 選項 | 說明 |
|------|------|
| 包含照片 | 下載時包含相關照片 |
| 包含天氣記錄 | 包含每日天氣資訊 |

## 篩選條件

- **工程案件**：指定特定工程
- **日期區間**：起訖日期
- **公司**：多公司環境下指定公司
- **狀態**：僅下載特定狀態的記錄
