# 工程監造系統 - 一般式工程管理

> 模組名稱: `construction_general`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供一般式工程的專屬管理功能，適用於 project_type = 'general' 的工程案件。

## 主要功能

### 1. 一般式自主檢查擴展
- 整合缺失改善功能
- 從檢查結果建立缺失

### 2. 一般式缺失改善 (general.defect.improvement)
- 獨立於通報單的缺失追蹤
- 完整改善流程
- 覆驗管理

### 3. 進度報告 (general.progress.report)
- 定期進度記錄
- 施工狀況描述
- 問題與對策

### 4. 即時損益 (general.realtime.profit)
- 即時損益計算
- 成本追蹤
- 利潤分析

## 選單位置

```
品質安全
└── 缺失管理
    ├── 一般式缺失改善
    └── 一般式逾期缺失

工程管理
└── 進度管理
    └── 進度報告

計價請款
└── 成本分析
    └── 即時損益
```

## 操作說明

### 建立一般式缺失改善
1. 進入「品質安全 > 缺失管理 > 一般式缺失改善」
2. 點擊「建立」按鈕
3. 選擇工程案件與工項
4. 填寫缺失資訊：
   - 缺失描述
   - 發現位置
   - 改善期限
5. 上傳缺失照片
6. 指派改善負責人
7. 開始追蹤改善進度

### 缺失改善流程
1. 施工單位填寫改善措施
2. 執行改善作業
3. 上傳改善後照片
4. 申請覆驗
5. 監造人員進行覆驗
6. 覆驗通過後結案

### 建立進度報告
1. 進入「工程管理 > 進度管理 > 進度報告」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 填寫報告內容：
   - 報告期間
   - 累計進度
   - 本期施工內容
   - 遭遇問題
   - 解決對策
5. 定期建立報告追蹤進度

### 查看即時損益
1. 進入「計價請款 > 成本分析 > 即時損益」
2. 選擇工程案件
3. 查看即時的損益狀況：
   - 契約收入
   - 累計成本
   - 目前損益
   - 預估最終損益

## 一般式 vs 預約式差異

| 項目 | 一般式 | 預約式 |
|------|--------|--------|
| 通報單 | 不需要 | 需要 |
| 缺失管理 | 一般式缺失改善 | 預約式缺失改善 |
| 自主檢查 | 一般式自主檢查 | 預約式自主檢查 |
| 進度管理 | 進度報告 | 通報單驗收 |
