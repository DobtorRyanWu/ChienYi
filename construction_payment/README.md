# 工程計價與請款管理

> 模組名稱: `construction_payment`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程專案的計價與請款功能，包含估驗計價、工項驗收與請款管理。

## 主要功能

### 1. 估驗計價 (payment.estimate)
- 分期估驗計畫
- 累計金額追蹤
- 預算 vs 實際對比

### 2. 工項驗收 (work.acceptance)
- 施工完成驗收
- 部分驗收支援
- 驗收結果記錄

### 3. 請款單 (payment.claim)
- 向業主請款
- 服務費與工程款請款
- 請款狀態追蹤

## 選單位置

```
計價請款
├── 估驗計價
│   ├── 估驗計價單
│   ├── 待審核估驗
│   └── 工項驗收單
└── 請款管理
    ├── 所有請款單
    ├── 服務費請款
    ├── 工程款請款
    └── 待處理請款
```

## 操作說明

### 建立估驗計價
1. 進入「計價請款 > 估驗計價 > 估驗計價單」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 填寫估驗資訊：
   - 估驗期數
   - 估驗日期
   - 估驗起訖期間
5. 新增估驗明細：
   - 選擇工項
   - 填寫本期完成數量
   - 系統自動計算金額
6. 儲存並提交審核

### 審核估驗計價
1. 監造人員進入「待審核估驗」
2. 檢視估驗內容與數量
3. 對照現場實際完成情況
4. 核准或退回修改

### 建立工項驗收
1. 進入「估驗計價 > 工項驗收單」
2. 選擇要驗收的工項
3. 填寫驗收數量
4. 記錄驗收結果
5. 通過後可納入估驗計價

### 建立請款單
1. 進入「請款管理 > 所有請款單」
2. 點擊「建立」按鈕
3. 選擇請款類型：
   - **服務費請款**：監造單位請款
   - **工程款請款**：施工廠商請款
4. 關聯估驗計價單
5. 系統帶入請款金額
6. 提交請款

### 請款審核
1. 審核人員進入「待處理請款」
2. 核對請款金額與依據
3. 核准或退回
4. 核准後進入撥款程序

## 工作流程

```
估驗計價流程：
草稿 → 已提交 → 已核准
              ↓
           已退回

請款流程：
草稿 → 已提交 → 審核中 → 已核准 → 已撥款
                     ↓
                  已退回
```
