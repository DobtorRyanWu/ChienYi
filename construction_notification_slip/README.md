# 工程監造系統 - 通報單管理

> 模組名稱: `construction_notification_slip`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供預約式工程的通報單管理功能，包含通報單建立、審核與驗收流程。

## 主要功能

### 1. 通報單管理 (reservation.notification.slip)
- 施工通報單建立
- 預定施工內容與數量登記
- 完整的審核流程
- 通報單狀態追蹤

### 2. 通報單明細 (reservation.notification.slip.line)
- 工項施工數量預報
- 預算金額計算
- 與契約工項關聯

### 3. 通報單驗收 (notification.acceptance)
- 施工完成後的驗收作業
- 實際完成數量確認
- 驗收結果記錄

### 4. 驗收明細 (notification.acceptance.line)
- 各工項驗收數量
- 合格/不合格標記
- 缺失說明

## 選單位置

```
施工執行
└── 通報單管理
    ├── 通報單
    ├── 待核准通報單
    ├── 執行中通報單
    └── 通報單驗收
        ├── 驗收單
        └── 待處理驗收單
```

## 操作說明

### 建立通報單
1. 進入「施工執行 > 通報單管理 > 通報單」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 設定預定施工日期
5. 新增通報單明細：
   - 選擇施工工項
   - 填寫預定施工數量
   - 系統自動計算預算金額
6. 儲存並送出審核

### 通報單審核
1. 監造人員進入「待核准通報單」
2. 檢視通報內容
3. 確認無誤後點擊「核准」
4. 如有問題點擊「退回」並填寫意見

### 通報單驗收
1. 施工完成後，進入「通報單驗收 > 驗收單」
2. 選擇對應的通報單
3. 填寫實際完成數量
4. 記錄驗收結果（合格/不合格）
5. 如有缺失，填寫缺失說明
6. 完成驗收

## 工作流程

```
通報單流程：
草稿 → 已提交 → 已核准 → 施工中 → 施工完成 → 已驗收
                ↓
              已退回

驗收單流程：
草稿 → 驗收中 → 驗收完成
           ↓
        待改善
```
