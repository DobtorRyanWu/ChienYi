# 工程監造系統 - 品質管理模組

> 模組名稱: `construction_quality`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程品質管理功能，包含自主檢查、缺失管理 (NCR) 與缺失改善追蹤。

## 主要功能

### 1. 自主檢查類型 (self.inspection.type)
- 檢查類型定義
- 檢查項目設定
- 適用工程類型設定

### 2. 一般式自主檢查 (general.self.inspection)
- 一般式工程專用
- 檢查表填寫
- 檢查結果記錄
- 缺失標記

### 3. 預約式自主檢查 (reservation.self.inspection)
- 預約式工程專用
- 與通報單關聯
- 檢查表填寫
- 缺失標記

### 4. 預約式缺失改善 (reservation.defect.improvement)
- 與通報單關聯
- 改善計畫填寫
- 改善進度追蹤

## 選單位置

```
品質安全
├── 自主檢查
│   ├── 一般式自主檢查
│   └── 預約式自主檢查
└── 缺失管理
    ├── 缺失管理 (NCR)
    ├── 逾期缺失
    ├── 預約式缺失改善
    ├── 一般式缺失改善
    └── 一般式逾期缺失

系統設定
└── 基礎設定
    └── 自主檢查類型
```

## 操作說明

### 執行自主檢查
1. 進入「品質安全 > 自主檢查」
2. 選擇對應的檢查類型（一般式/預約式）
3. 點擊「建立」按鈕
4. 選擇工程案件與工項
5. 填寫檢查日期
6. 逐項填寫檢查結果
7. 如有不合格項目，勾選「缺失」
8. 完成檢查並儲存

### 建立缺失改善
1. 進入「品質安全 > 缺失管理」，依工程類型選「一般式監造/營造缺失改善」或「預約式缺失改善」
2. 點擊「建立」按鈕
3. 填寫缺失資訊：
   - 缺失描述
   - 發現位置
   - 缺失等級
   - 改善期限
4. 上傳缺失照片
5. 指派改善負責人
6. 儲存並開始追蹤

### 缺失改善追蹤
1. 進入對應的缺失記錄
2. 查看目前狀態
3. 填寫改善措施
4. 上傳改善後照片
5. 申請覆驗
6. 覆驗通過後結案

### 監控逾期缺失
1. 進入「缺失管理 > 逾期缺失」
2. 查看已逾期未改善的缺失
3. 督促相關人員處理
4. 必要時調整改善期限

## 缺失狀態流程

```
開立 (open)
    ↓
調查中 (investigating)
    ↓
已採取措施 (action_taken)
    ↓
已驗證 (verified)
    ↓
已結案 (closed)
```
