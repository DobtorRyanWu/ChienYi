# 工程監造系統 - 時程控制模組

> 模組名稱: `construction_timeline`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程時程控制與視覺化功能，包含甘特圖視圖、施工計時器與時程差異分析。

## 主要功能

### 1. Timeline 甘特圖視圖
- 視覺化工項時程
- 拖曳調整時程
- 相依關係顯示

### 2. 施工計時器
- 開始/結束施工計時
- 即時工時記錄
- 與工時表整合

### 3. 時程差異分析
- 預定 vs 實際時程對比
- 差異計算與警示
- 進度落後追蹤

## 選單位置

```
工程管理
└── 進度管理
    ├── 工項時程
    ├── 時程分析
    │   ├── 時程差異分析
    │   ├── 進度落後工項
    │   ├── 時程警示工項
    │   └── 關鍵路徑工項
    └── 進度表

施工執行
└── 工時管理
    ├── 我的計時器
    └── 執行中工時
```

## 操作說明

### 查看工項時程
1. 進入「工程管理 > 進度管理 > 工項時程」
2. 選擇工程案件
3. 以甘特圖方式查看工項時程
4. 可拖曳調整工項的開始與結束日期

### 使用施工計時器
1. 進入「施工執行 > 工時管理 > 我的計時器」
2. 選擇要計時的工項
3. 點擊「開始計時」
4. 施工完成後點擊「結束計時」
5. 系統自動記錄工時

### 時程差異分析
1. 進入「進度管理 > 時程分析 > 時程差異分析」
2. 查看各工項的時程差異：
   - 預定開始/結束日期
   - 實際開始/結束日期
   - 差異天數
3. 紅色標記為落後工項

### 監控落後工項
1. 進入「時程分析 > 進度落後工項」
2. 查看所有進度落後的工項
3. 分析落後原因
4. 制定追趕計畫

## 時程狀態

| 狀態 | 說明 |
|------|------|
| 正常 | 實際進度符合預定 |
| 超前 | 實際進度超過預定 |
| 落後 | 實際進度落後預定 |
| 警示 | 即將逾期或剛開始落後 |
