# 工程監造系統 - 工程相關單位管理

> 模組名稱: `construction_partner`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程相關單位的擴展管理功能，包含分類標籤、證照管理與技術聯絡人。

## 主要功能

### 1. 工程單位分類標籤
- 樹狀分類結構
- 多層級分類
- 快速篩選

### 2. 廠商證照管理 (partner.license)
- 證照資料登錄
- 有效期限追蹤
- 到期提醒

### 3. 技術聯絡人 (partner.technical.contact)
- 專案技術聯絡人
- 聯絡資訊維護
- 專長領域標記

### 4. 聯絡人擴展 (res.partner)
- 工程相關欄位
- 營造廠商等級
- 工程表現評鑑

## 選單位置

```
工程管理
└── 資源管理
    ├── 工程單位
    │   ├── 所有單位
    │   ├── 施工廠商
    │   ├── 監造/設計單位
    │   └── 業主單位
    ├── 技術聯絡人
    ├── 廠商證照
    └── 即將過期證照
```

## 操作說明

### 管理工程單位
1. 進入「工程管理 > 資源管理 > 工程單位」
2. 可依分類查看：施工廠商、監造單位、業主等
3. 點擊「建立」新增單位
4. 填寫單位資訊：
   - 單位名稱
   - 統一編號
   - 聯絡資訊
   - 單位分類
5. 儲存單位資料

### 登錄廠商證照
1. 進入「資源管理 > 廠商證照」
2. 點擊「建立」按鈕
3. 選擇所屬廠商
4. 填寫證照資訊：
   - 證照類型
   - 證照號碼
   - 發證日期
   - 有效期限
5. 上傳證照掃描檔
6. 儲存證照記錄

### 監控即將過期證照
1. 進入「資源管理 > 即將過期證照」
2. 查看 30 天內即將到期的證照
3. 通知廠商辦理換照
4. 更新證照資訊

### 管理技術聯絡人
1. 進入「資源管理 > 技術聯絡人」
2. 建立專案技術聯絡人資訊
3. 記錄聯絡方式與專長領域
4. 指派至對應工程案件

```
├── 建築監造
├── 結構監造

設計單位
├── 建築師事務所

└── 機電技師事務所

政府部門
├── 主管機關
├── 消防單位
└── 環保單位
```
