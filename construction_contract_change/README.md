# 工程監造系統 - 契約變更管理

> 模組名稱: `construction_contract_change`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程契約變更追蹤與管理功能。

## 主要功能

### 1. 契約變更單 (contract.change.order)
- 變更單建立與追蹤
- 完整的審核流程
- 變更金額計算

### 2. 變更明細 (contract.change.order.line)
- 工項新增、修改、刪除
- 金額/數量/工期變更
- 自動更新專案契約資訊

## 選單位置

```
工程管理
└── 契約管理
    ├── 契約變更單
    ├── 待處理變更單
    └── 已套用變更單
```

## 操作說明

### 建立契約變更單
1. 進入「工程管理 > 契約管理 > 契約變更單」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 填寫變更單資訊：
   - 變更單編號（自動產生）
   - 變更原因說明
   - 變更日期
5. 新增變更明細

### 新增變更明細
1. 在變更單中點擊「新增明細」
2. 選擇變更類型：
   - **新增**：新增工項
   - **修改**：修改既有工項
   - **刪除**：刪除工項
3. 填寫工項資訊與變更內容
4. 系統自動計算變更金額

### 提交審核
1. 確認變更內容無誤
2. 點擊「提交審核」
3. 狀態變更為「已提送」
4. 等待審查

### 審核變更單
1. 審查人員進入「待處理變更單」
2. 檢視變更內容與金額
3. 核定後點擊「核准」
4. 如有問題點擊「駁回」

### 套用變更
1. 核准後的變更單可執行套用
2. 點擊「套用變更」按鈕
3. 系統自動：
   - 更新專案契約金額
   - 新增/修改/刪除工項
   - 記錄累計變更
4. 狀態變更為「已套用」

## 狀態流程

```
草稿 (draft)
    ↓
已提送 (submitted)
    ↓
審查中 (reviewing)
    ↓
已核定 (approved) ←→ 已駁回 (rejected)
    ↓
已套用 (applied)
```

## 變更類型

| 類型 | 說明 |
|------|------|
| 新增 | 新增契約工項 |
| 修改 | 修改既有工項的數量、單價或規格 |
| 刪除 | 刪除既有工項 |
