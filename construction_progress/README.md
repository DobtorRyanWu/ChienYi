# 工程監造系統 - 進度表管理

> 模組名稱: `construction_progress`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程進度表管理功能，支援每周、每兩周與自訂計算模式。

## 主要功能

### 1. 進度表管理 (progress.schedule)
- 每個專案可有多版進度表
- 支援三種計算模式
- 累計進度自動計算

### 2. 進度表明細 (progress.schedule.line)
- 時間區間進度規劃
- 預定進度填寫
- 實際進度同步

## 選單位置

```
工程管理
└── 進度管理
    ├── 進度表
    └── 進度明細
```

## 操作說明

### 建立進度表
1. 進入「工程管理 > 進度管理 > 進度表」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 選擇計算模式：
   - **每周**：自動產生每周區間
   - **每兩周**：自動產生每兩周區間
   - **自訂**：手動新增時間區間
5. 設定進度表期間（起訖日期）
6. 儲存後系統自動產生時間區間

### 填寫預定進度
1. 開啟進度表
2. 在各時間區間填寫預定進度（%）
3. 系統自動計算累計預定進度
4. 儲存進度表

### 更新實際進度
1. 從施工日誌同步實際進度
2. 或手動填寫各區間實際完成進度
3. 系統自動計算累計實際進度
4. 比對差異並顯示進度狀態

### 進度分析
1. 查看進度差異（實際 - 預定）
2. 正值表示超前，負值表示落後
3. 系統自動標記進度狀態

## 計算模式說明

| 模式 | 說明 |
|------|------|
| 每周 | 以週為單位自動產生進度區間 |
| 每兩周 | 以兩週為單位自動產生進度區間 |
| 自訂 | 使用者自行定義時間區間 |

## 進度狀態

| 狀態 | 條件 | 顏色 |
|------|------|------|
| 超前 | 差異 > 2% | 綠色 |
| 正常 | -2% ≤ 差異 ≤ 2% | 藍色 |
| 落後 | 差異 < -2% | 紅色 |
