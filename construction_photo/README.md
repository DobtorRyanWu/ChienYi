# 工程監造系統 - 照片管理模組

> 模組名稱: `construction_photo`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程照片管理功能，支援 GPS 位置記錄與來源追蹤。

## 主要功能

### 1. 工程照片管理 (supervision.photo)
- 照片上傳與管理
- GPS 位置記錄
- 拍攝資訊記錄
- 來源追蹤（施工日誌、自主檢查等）

### 2. 照片標籤 (supervision.photo.tag)
- 標籤分類系統
- 多標籤支援
- 快速篩選

## 選單位置

```
施工執行
└── 照片管理
    ├── 工程照片
    └── 照片標籤
```

## 操作說明

### 上傳工程照片
1. 進入「施工執行 > 照片管理 > 工程照片」
2. 點擊「建立」按鈕
3. 選擇工程案件
4. 上傳照片檔案
5. 填寫照片資訊：
   - 照片說明
   - 拍攝日期
   - 拍攝位置描述
   - GPS 座標（如有）
6. 選擇適用標籤
7. 儲存照片記錄

### 從其他模組關聯照片
照片可從以下來源自動關聯：
- 施工日誌上傳的照片
- 自主檢查表的檢查照片
- 缺失改善的改善前/後照片
- 驗收作業的驗收照片

### 管理照片標籤
1. 進入「照片管理 > 照片標籤」
2. 建立常用標籤：
   - 施工前
   - 施工中
   - 施工後
   - 材料進場
   - 缺失照片
   - 改善照片
3. 在上傳照片時選擇適用標籤

### 搜尋與篩選照片
1. 使用標籤篩選特定類型照片
2. 依日期範圍篩選
3. 依工程案件篩選
4. 依來源類型篩選

## 照片來源類型

| 來源 | 說明 |
|------|------|
| 施工日誌 | 每日施工記錄附件 |
| 自主檢查 | 檢查過程照片 |
| 缺失改善 | 缺失與改善照片 |
| 通報單 | 施工通報相關照片 |
| 驗收作業 | 驗收過程照片 |
| 手動上傳 | 直接上傳的照片 |
