# 工程監造系統 - 檢試驗管理模組

> 模組名稱: `construction_test`
> 版本: 18.0.1.0.0

## 模組說明

此模組提供工程檢試驗管理功能，包含試驗項目設定與試驗記錄管理。

## 主要功能

### 1. 檢試驗項目管理 (supervision.test.standard)
- 試驗工項/材料設定
- 依據方法與規範要求
- 頻率與下限設定
- 取樣規則與條件
- 關聯契約工項

### 2. 檢(試)驗管制記錄 (supervision.test.record)
- 材料進場記錄
- 取樣記錄與累計統計
- 抽驗人員記錄
- 試驗結果判定
- 歸檔編號管理
- 檢驗報告附件

## 選單位置

```
品質安全
└── 檢試驗管理
    ├── 檢試驗項目管理
    ├── 檢(試)驗管制記錄
    └── 設定
```

## 操作說明

### 設定檢試驗項目
1. 進入「品質安全 > 檢試驗管理 > 檢試驗項目管理」
2. 點擊「建立」按鈕
3. 填寫試驗項目資訊：
   - 項目名稱（如：混凝土抗壓試驗）
   - 試驗材料/工項
   - 依據規範（如：CNS 1232）
   - 取樣頻率（如：每 100m³ 取樣一組）
   - 下限數量
4. 關聯適用的契約工項
5. 儲存設定

### 建立試驗記錄
1. 進入「品質安全 > 檢試驗管理 > 檢(試)驗管制記錄」
2. 點擊「建立」按鈕
3. 選擇工程案件與試驗項目
4. 填寫記錄資訊：
   - 材料進場日期與數量
   - 取樣日期與數量
   - 抽驗人員
   - 送驗單位
5. 系統自動計算累計進場數量與取樣數量
6. 儲存記錄

### 登錄試驗結果
1. 收到試驗報告後，開啟對應記錄
2. 填寫試驗結果：
   - 試驗日期
   - 試驗結果（合格/不合格）
   - 試驗值數據
3. 上傳試驗報告附件
4. 填寫歸檔編號
5. 儲存完成

### 查看統計分析
1. 使用篩選器查看特定材料的試驗記錄
2. 系統自動計算取樣率
3. 檢視累計統計數據
4. 匯出報表供審查使用

## 計算說明

| 項目 | 計算公式 |
|------|----------|
| 累計進場數量 | 各批次進場數量加總 |
| 累計取樣數量 | 各批次取樣數量加總 |
| 取樣率 | 累計取樣數量 ÷ 累計進場數量 × 100% |
